# 등산은 하고 싶은데, 벌레가 싫다면? 벌레 적은 산을 찾아가면 된다!

산림 공공데이터로 100대 명산마다 '벌레 지수'를 계산해, 벌레가 적게 기록된 산을 찾은 개인 분석입니다.
2026 산림공공데이터 활용사례 공모(자체 활용형) 제출용 저장소입니다.

## 왜 만들었나

벌레가 너무 싫어서 "산에 가면 벌레가 많을 것"이라는 생각에 등산을 피해 왔습니다.
정말 산에 벌레가 많은지, 벌레를 덜 만나는 산은 없는지 공공데이터로 확인하고 첫 산행지를 고르려고 분석했습니다.

## 쓴 데이터

| 데이터 | 형식 | 쓴 내용 |
| --- | --- | --- |
| [산림청 국립산림과학원_절지동물분포조사자료](https://www.data.go.kr/data/15156597/openapi.do) | 오픈API | 조사지역 정보(조사지 366곳의 위치·해발고도·기온·강수량 등), 임상별 조사자료(벌레 기록 5,517줄, 226,117마리) |
| [한국등산트레킹지원센터_산림청 100대명산](https://www.data.go.kr/data/15098177/fileData.do) | 파일(GPX) | 100개 산, 등산 코스 607개의 위치·고도 |

- 두 데이터 모두 공공데이터포털에서 받았고 이용허락범위 제한이 없습니다.
- 같은 366곳을 다룬 국립산림과학원 연구진 논문(Kwon et al., 2023)에 따르면, 절지동물 자료는 2006~2009년 5~9월에 땅에 컵을 묻는 함정트랩으로 지점마다 한 번씩 조사한 결과입니다. API에는 조사 연도 항목이 없어 추정입니다.

## 분석 방법

1. **API 결과 정리** (`code/1_parse_api.py`): 공공데이터포털 미리보기로 저장한 XML 7개(조사지역 1페이지, 임상별 조사자료 6페이지)를 CSV로 바꿉니다.
2. **산 정보 만들기** (`code/2_parse_gpx.py`): GPX 607개에서 산마다 정상 위치·높이와 코스 최저 고도를 뽑습니다. 대암산 GPX는 고도가 모두 0이라 비워 둡니다.
3. **정리** (`code/3_clean.py`)
   - 좌표 '37 37 36.7'(도·분·초 글자)을 소수점 숫자로 바꿉니다.
   - 벌레를 생물 분류의 강(곤충강·거미강·지네강·노래기강·갑각강)으로 나눕니다. 목 이름 오타·표기 차이 98줄을 고치고, 목과 강이 맞지 않는 50줄은 목을 기준으로 바로잡습니다.
   - 톡토기목·응애목(너무 작아 눈에 거의 안 띔)과 파리목(날벌레라 바닥 컵으로 대표하기 어려움)을 빼고 119,322마리를 분석합니다.
   - 벌레 기록이 있는 조사지는 262곳입니다. 이 중 125곳은 낙엽·관목·초본 피복도가 모두 0이고, 같은 도 안에서도 벌레가 적게 기록돼 조사 방식이 다른 묶음(B)으로 표시합니다.
4. **산별 벌레 지수** (`code/4_match.py`)
   - 산마다 정상 반경 30km 안, 해발고도가 '코스 최저점 −150m ~ 정상 +100m'인 조사지를 고릅니다. 3곳 미만이면 50km로 넓힙니다.
   - 평균 거리가 50km를 넘는 섬 3곳(한라산·성인봉·깃대봉)은 비교에서 빼서 97개 산을 비교합니다.
   - 조사지마다 같은 묶음 안에서의 백분위를 구하고, 산마다 그 평균을 지수(0~100, 낮을수록 적음)로 씁니다.
5. **검증과 특징 분석** (`code/5_check_and_traits.py`)
   - 조사지를 1,000번 다시 뽑아 계산, 하나씩 빼고 계산, 기준 6가지로 바꿔 계산
   - 조사 묶음 차이와 피복도 착시 확인
   - 도별·강수량별 점수, 벌레 적은 산과 많은 산의 환경 비교

## 주요 결과

| 구분 | 결과 |
| --- | --- |
| 벌레(전체)가 적게 기록된 산 | 두륜산 8.4, 선운산 13.7, 변산 15.0 |
| 거미강이 적게 기록된 산 | 선운산 14.3, 천관산 16.1, 변산 16.2 |
| 벌레가 많이 기록된 산 | 미륵산, 적상산, 지리산(통영) |
| 순위 검증 | 1,000번 다시 뽑아 5위 안에 든 비율: 두륜산 99%, 선운산 95%, 변산 88% |
| 기준 바꾸기 | 선운산은 6가지 기준 모두 거미강 1~3위, 전체 5위 안 |
| 지역 | 적은 10곳 중 8곳이 충남·전북·전남, 많은 10곳 중 6곳이 경남 쪽 조사지 |
| 비 | 강수량이 적은 구간보다 중간·많은 구간의 점수가 높음(41 → 56 → 56) |
| 높이·기온 | 전체 벌레 수와 뚜렷한 관계 없음(해발 1,031m 이하) |

자세한 숫자는 `results/check_report.md`, 산별 지수는 `results/100대명산_벌레지수.csv`에 있습니다.

## 한계

- 2006~2009년 여름 조사로 보이는 과거 기록이라, 지금 산의 벌레 수를 알려 주는 예보가 아닙니다.
- 조사지 366곳 중 104곳은 벌레 기록이 없고, 해발 1,000m 넘는 곳은 거의 다 여기에 해당합니다.
- 함정트랩 조사라 모기·날파리 같은 날벌레는 알 수 없습니다.
- 산별 점수는 그 산 자체가 아니라 정상 주변 조사지의 기록입니다. 산마다 쓴 조사지는 3~11곳입니다.
- 환경 항목으로 설명되는 벌레 수 차이는 10% 안팎(거미강 25%)입니다.

## 폴더 구성

```
code/                     분석 코드(1~5단계, common.py는 공통 함수)
data/raw_api/             공공데이터포털 미리보기로 저장한 API 결과 XML
data/raw_gpx/             100대명산 GPX zip을 넣는 곳(용량 때문에 저장소에는 없음)
data/sites_raw.csv        조사지 366곳(API 원자료를 CSV로)
data/records_raw.csv      벌레 기록 5,517줄(API 원자료를 CSV로)
data/mountains_from_gpx.csv  100대 명산 정상 위치·고도
results/                  산별 벌레 지수, 검증·특징 결과, Power BI용 표
```

## 다시 실행하는 법

```
pip install -r requirements.txt
python code/1_parse_api.py
python code/2_parse_gpx.py      # data/raw_gpx/에 GPX zip을 넣었을 때만
python code/3_clean.py
python code/4_match.py
python code/5_check_and_traits.py
```

- API 인증키는 저장소에 넣지 않았습니다. XML은 공공데이터포털 미리보기 결과를 저장한 것이라 키가 들어 있지 않습니다.
- `data/mountains_from_gpx.csv`가 들어 있어서 GPX 없이도 3~5단계를 실행할 수 있습니다.
